# Plugin Hub submission

After publishing this repository publicly as `zDezo/farming-discord-status-plugin`:

1. Fork `runelite/plugin-hub` on GitHub.
2. Create a branch from the latest `master` branch.
3. Add `plugins/farming-discord-status` containing:

```text
repository=https://github.com/zDezo/farming-discord-status-plugin.git
commit=REPLACE_WITH_THE_FULL_COMMIT_HASH_FROM_THIS_REPOSITORY
```

4. Commit that marker file and open a pull request to `runelite/plugin-hub:master`.
5. Suggested pull request title: `Add Farming Discord Status`
6. Suggested description: `Adds a farming timer companion that sends opt-in RuneLite Time Tracking summaries and ready alerts to the user's private Discord DMs.`

If this repository is published under a different name, update the marker's `repository` URL before submitting.
